# COS 106 Term Project: Responsive Student Portfolio & Academic Management Website

## Project Overview
A multi-page responsive student portfolio and academic planner web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript** for MIVA Open University (`COS 106 - Introduction to Web Technologies`).

## Folder Structure
```text
cos106-student-portfolio/
├── index.html          # Homepage (profile, welcome message, navigation, biography)
├── about.html          # About Me (education table, career goals, skills list, audio intro)
├── projects.html       # Projects Showcase (3 sample projects with filter, screenshots & links)
├── planner.html        # Interactive Academic Planner (add, complete, delete tasks via JS)
├── contact.html        # Contact Page (JS validation for non-empty, email & digits-only phone)
├── css/
│   └── style.css       # External stylesheet (CSS Grid, Flexbox, animations, media queries)
├── js/
│   └── script.js       # External JavaScript (DOM manipulation, validation, task management)
├── assets/
│   ├── profile.png
│   ├── project1.png
│   ├── project2.png
│   ├── project3.png
│   └── welcome-intro.wav
└── README.md
```

## How to Host on GitHub Pages
1. Create a new public repository on GitHub (e.g., `cos106-student-portfolio`).
2. Upload all files and folders inside `cos106-student-portfolio/` to the root of the repository.
3. Go to **Settings > Pages**, select the `main` branch and `/ (root)` folder, and click **Save**.
4. Submit both your live GitHub Pages URL and your GitHub repository link.
